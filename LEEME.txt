BOUTIQUE UADY EN LINEA - Frontend en XAMPP (htdocs) + backend Java (Tomcat)
===========================================================================

Estructura de esta carpeta
  index.html, login.html, registro.html, catalogo.html, carrito.html, assets/, fotos boutique/
      -> frontend: se sirve desde Apache de XAMPP (http://localhost/BoutiqueUADY/)
  backend-java/
      -> proyecto Maven (NetBeans) con los servlets en Java. Apache NO lo sirve (.htaccess lo bloquea).

Como funciona
  El navegador abre todo en  http://localhost/BoutiqueUADY/  (Apache, puerto 80).
  Las peticiones a  /BoutiqueUADY/api/...  las reenvia Apache a Tomcat (puerto 8080).
  Para el navegador es un solo origen: sin problemas de CORS y la sesion funciona.
  Base de datos: MySQL de XAMPP (puerto 3306), BD boutique_uady, usuario root sin contrasena.

PASOS
 1) Copiar la carpeta BoutiqueUADY completa a  C:\xampp\htdocs\
 2) En el Panel de XAMPP iniciar Apache y MySQL.
 3) Abrir C:\xampp\apache\conf\httpd.conf y pegar al final el contenido de
    backend-java\apache-proxy.conf.  Verificar que estas dos lineas NO esten comentadas con #:
        LoadModule proxy_module modules/mod_proxy.so
        LoadModule proxy_http_module modules/mod_proxy_http.so
    Guardar y reiniciar Apache (Stop / Start).
 4) En NetBeans: File > Open Project > C:\xampp\htdocs\BoutiqueUADY\backend-java
    Properties > Run > Server: Apache Tomcat 10.1 (o superior).  Clean and Build y luego Run.
    (El Context Path ya queda en /BoutiqueUADY por META-INF/context.xml. Si NetBeans abre una
     pagina en el puerto 8080 y da 404, es normal: usar la direccion del paso 5.)
 5) Abrir  http://localhost/BoutiqueUADY/

Si algo falla
  - Pagina carga pero login/registro dicen "No se pudo conectar con el servidor":
    Tomcat no esta corriendo, o el proxy de Apache no esta activo (paso 3).
  - Probar la API directo:  http://localhost:8080/BoutiqueUADY/api/sesion  debe devolver {"autenticado":false}
    y tambien por Apache:   http://localhost/BoutiqueUADY/api/sesion
  - Si la carpeta en htdocs tiene otro nombre, cambiar /BoutiqueUADY en apache-proxy.conf y en
    backend-java\src\main\webapp\META-INF\context.xml (deben coincidir con el nombre de la carpeta).
  - Si cambias el usuario/clave/puerto de MySQL: backend-java\src\main\java\mx\uady\boutique\dao\ConexionBD.java
  - Pruebas unitarias: en backend-java ejecutar  mvn test
